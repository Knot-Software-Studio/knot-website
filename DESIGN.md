# Knot Software Studio · Design System

## 1. Visual World & Authentic Logo Grounding
- **Official Knot Quad-Tone Palette**:
  - `#BEC0E9` (Frost Lilac — high-contrast crisp accent for primary buttons and focus states)
  - `#979BC1` (Slate Periwinkle — secondary interactive elements, badges, highlights)
  - `#5C6282` (Steel Indigo — deep container accents, borders, and dark structural tones)
  - `#202A45` (Midnight Slate — dark grounding tone and structural canvas depth)
- **Typographic Dialectic**:
  - **Instrument Serif**: Expressive, poetic, high-fashion editorial serif for key statements and section headers.
  - **Manrope**: High-legibility precision sans-serif for UI components, buttons, and reading text.
  - **JetBrains Mono**: Technical metadata, indices, timestamps, and server specs.
- **Slogan Hierarchy**: *"Software die verbindet."* / *"Für Momente, die bleiben."* / *"Österreichisches Indie Software Studio."*
